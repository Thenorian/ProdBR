Consulta de tributos

Uma URL, uma resposta JSON pronta para usar no seu sistema, do mesmo jeito que o ViaCEP. Informe o país, a UF/província e o NCM ou o código de barras e receba todos os tributos daquele lugar, com o nome traduzido, a alíquota e a fonte. Sem cadastro, sem chave e de graça.

Testar agora

URL: 


  


  
Endereços

  

    
      
GET /v1/{país}/{uf}/{ncm}Tributos do NCM na UF/província. Ex: /v1/BR/SP/23091000

      
GET /v1/{país}/{ncm}Só os tributos nacionais. Ex: /v1/AR/23091000

      
GET /v1/{país}/{uf}/{código de barras}Pelo GTIN/EAN: devolve também o produto e a embalagem.

      
GET /v1/{país}As UFs/províncias e os tributos cadastrados no país. Ex: /v1/UY

      
?lang=pt|es|enIdioma dos nomes dos tributos (padrão: o do país).

      
?date=2027-01-01Tributos vigentes em outra data.

      
?cest=0000000Regra específica de um CEST (Brasil).

    
  

  
Cada tributo vem com rate (alíquota). general_rate: true quer dizer que ainda não há regra para esse NCM e a alíquota é a geral do país. Quando rate vem null, o tributo existe mas ainda não tem dado: cadastre. Os códigos de país seguem a ISO 3166-1 e os de UF/província a ISO 3166-2.


  
Exemplos

  
curl {{ base_url }}/v1/BR/SP/23091000

// JavaScript
const r = await fetch("{{ base_url }}/v1/AR/B/23091000?lang=pt").then(r => r.json());
r.taxes.forEach(t => console.log(t.name, t.rate));

# Python
import json, urllib.request
dados = json.load(urllib.request.urlopen("{{ base_url }}/v1/UY/MO/23091000"))


  
Rodar na sua máquina

  
O ProdBR é 100% código aberto. Uma cópia local sobe já com os países, as UFs/províncias e os tributos do Mercosul. No primeiro minuto, ela baixa sozinha a tabela NCM e o IPI/II oficiais e depois atualiza todo dia.

  
git clone https://github.com/Thenorian/ProdBR.git
cd ProdBR
docker compose up -d          # pronto em http://localhost:8000

# sem Docker:
pip install -r requirements.txt
uvicorn app.main:app --port 8000

  
Para ter também os produtos desta instância, baixe a base completa em /export/sqlite.
