Sobre o projeto

Dado um código de barras, GTIN ou NCM, o ProdBR devolve nome, marca, categoria e a classificação fiscal do produto — e, à parte, as alíquotas de referência (ICMS, IPI, PIS, COFINS, CBS/IBS e mais) dessa classificação. Cadastre uma vez e todo sistema com o mesmo NCM se beneficia.

Um mesmo produto pode ter vários códigos de barras — um para cada embalagem (1 kg, 2 kg, 15 kg...) — porque os dados fiscais são os mesmos. Leia mais sobre o projeto.

Para desenvolvedores

Toda leitura é pública, sem autenticação. Para contribuir, crie uma conta e use a sua chave de API (veja Minha conta) no header X-API-Key. 

curl "https://prodbr.thenorian.com/products?ncm=22030000"
