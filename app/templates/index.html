Sobre o projeto

O ProdBR é uma base aberta de identificação de produtos brasileiros: dado um código de barras, GTIN ou NCM, ela devolve nome, marca, categoria e a classificação fiscal do produto — e, à parte, as alíquotas de referência (ICMS, IPI, PIS, COFINS, CBS/IBS e mais) aplicáveis a essa classificação. Existe pra evitar que cada sistema precise descobrir do zero qual é o NCM e a tributação de um produto: cadastre uma vez, todo mundo com o mesmo NCM se beneficia. Mantido pela Thenorian, mas aberto — qualquer pessoa pode consultar, contribuir ou hospedar sua própria cópia. Leia mais sobre o projeto →

Como usar a API

Toda leitura é pública, sem autenticação. Pra contribuir (cadastrar ou editar), crie uma conta e use a chave de API pessoal (mostrada uma única vez no cadastro — veja Minha conta se precisar gerar uma nova) no header X-API-Key: 

curl "https://sua-instancia/products?ncm=22030000"

curl -X POST "https://sua-instancia/products" \
  -H "X-API-Key: SUA_CHAVE_AQUI" \
  -H "Content-Type: application/json" \
  -d '{"name":"Cerveja 600ml","ncm":"22030000","source":"fabricante","reason":"cadastro inicial"}'

Documentação interativa completa (todos os endpoints, testável direto no navegador) em /docs (Swagger).
