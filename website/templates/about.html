Sobre o ProdBR

Uma base aberta de produtos brasileiros, para nenhum sistema precisar cadastrar do zero. Pelo código de barras vêm nome, marca, empresa, NCM, categoria, preço de venda e tributação de referência.

Como surgiu

O ProdBR nasceu dentro da Thenorian para resolver um problema dos nossos próprios sistemas, como o Simple ERP e o OS-Mechanical: cada cliente cadastrava os mesmos produtos à mão, com NCM, CEST e tributação que mudam o tempo todo.

Em vez de manter essa base fechada, decidimos abrir. Hoje qualquer pessoa ou sistema consulta de graça, sem cadastro, e qualquer um pode contribuir, como numa Wikipedia de produtos. Quanto mais gente usa e corrige, melhor fica para todos.

Como funciona

Toda alteração fica registrada no histórico público, como no Git. Quem está começando tem as alterações revisadas pela comunidade na fila de votação; com o tempo, ganha reputação e passa a gravar direto. Veja quem mais contribui.

Quem mantém

O ProdBR é desenvolvido e mantido pela equipe da Thenorian. O código é aberto e está no GitHub, onde dá para acompanhar tudo e sugerir melhorias.

API

Consulta livre, sem chave. Para alterar, use o seu token no cabeçalho X-API-Key.

GET /api/v1/barcode/{código de barras}
GET /api/v1/products?ncm=22030000
GET /api/v1/products?manufacturer=Tramontina
GET /api/v1/products?manufacturer_code=BPR6ES
GET /api/v1/categories

Dados abertos

A base inteira pode ser baixada em SQLite, sob a licença ODbL. O código é AGPLv3.

Parte dos produtos vem do Open Food Facts, também sob ODbL. Cada produto mostra a sua fonte.

A carga tributária aproximada vem da tabela do IBPT (Lei 12.741/2012), atualizada todo dia.
