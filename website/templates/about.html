Sobre o ProdBR

Uma base aberta de produtos brasileiros, para nenhum sistema precisar cadastrar do zero. Pelo código de barras vêm nome, marca, NCM, categoria, preço médio e tributação de referência.

Qualquer pessoa consulta e contribui. Toda alteração fica registrada no histórico, como no Git.

API

Consulta livre, sem chave. Para alterar, use o seu token no cabeçalho X-API-Key.

GET /api/v1/barcode/{código de barras}
GET /api/v1/products?ncm=22030000
GET /api/v1/products?manufacturer=Tramontina
GET /api/v1/products?manufacturer_code=BPR6ES
GET /api/v1/categories

Dados abertos

A base inteira pode ser baixada em SQLite, sob a licença ODbL. O código é AGPLv3.

Parte dos produtos vem do Open Food Facts, também sob ODbL. Cada produto mostra a sua fonte.

A carga tributária aproximada vem da tabela do IBPT (Lei 12.741/2012), atualizada todo dia.
